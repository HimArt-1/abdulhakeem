# منصة «كيف تُصنع؟» (Kaif Tosna'?)
> **«كل منتج له حكاية… ادخلها»**
> منصة ويب عربية تفاعلية لاكتشاف المصانع الوطنية وتنظيم الزيارات الميدانية والجولات التعليمية والتجارية.

---

## 🎨 فلسفة التصميم ونظام الألوان (Design System)

* **العربية أولًا (Arabic First):** اتجاه RTL كامل مع خطوط عربية واضحة ومريحة للقراءة (`IBM Plex Sans Arabic`).
* **طابع استكشافي تحريري:** بطاقات منتجات ومصانع فسيحة، ميكرو-أنيميشن هادئ مع دعم كامل لتقليل الحركة (`prefers-reduced-motion`).
* **لوحة الألوان المتناسقة:**
  * **الخلفية العاجية الدافئة:** `#FAF7F2` و `#FFFDF9`.
  * **النص الفحمي المتوازن:** `#1E2022` و `#444950`.
  * **اللون النحاسي للأفعال الأساسية:** `#B86532` (Copper) يعبر عن الأصالة والصناعة الوطنية.
  * **ألوان مميزة لكل قطاع صناعي:**
    * ☕ **القهوة والمشروبات:** بني محمص (`#8C4B27`)
    * 🍫 **الشوكولاتة والحلويات:** كاكاو داكن (`#5E2E17`)
    * 🌸 **العطور والتقطير:** بنفسجي ملكي معتق (`#7C3A84`)
    * 🏺 **الخزف والفنون:** أحمر طيني ترابي (`#B04A2F`)
    * ♻️ **الورق وإعادة التدوير:** أخضر زمردي مستدام (`#286E53`)

## 🏭 المصانع الخمسة الافتراضية المعتمدة (بيانات تجريبية واقعية)

1. **محمصة ومصنع مسار البن (الرياض):** «من الحبّة إلى الفنجان» — محامص هوائية ذكية ومختبر تقييم حسي معتمد.
2. **مصنع قطيفة للكاكاو والشوكولاتة الحرفية (جدة):** «من الكاكاو إلى أول قضمة» — خط إنتاج حبة إلى لوح (Bean-to-Bar) مع طواحين حجرية تدور 72 ساعة.
3. **دار نفحات للزيوت العطرية والتقطير (الطائف):** «اصنع حكايتك العطرية» — قدور نحاسية تقليدية لتقطير الورد الطائفي واستخلاص الزيوت العطرية.
4. **أتيليه ومسبك فخار وادي حنيفة (الرياض):** «من الطين إلى قطعة تحمل اسمك» — تشكيل خزفي على العجلة وأفران حرق بدرجة 1250 مئوية.
5. **مصنع تجديد لتقنيات الورق المستدام (الدمام):** «حياة جديدة لورقة قديمة» — هيدروبلبر عملاق وأسطوانات تجفيف لإعادة تدوير الورق 100%.

## 🚀 رحلة الاستخدام الكاملة المطبقة في النظام (End-to-End)

1. **صفحة الاكتشاف (Discover):**
   * سؤال رئيسي: «وش ودّك تعرف كيف يُصنع؟».
   * 5 بطاقات تفاعلية للرحلات الخمس، مع إمكانية الانتقال المباشر لكل مصنع.
   * بحث فوري وتصفية بحسب المدينة (الرياض، جدة، الطائف، الدمام)، القطاع، وغرض الزيارة.
   * حالة واضحة لعدم وجود نتائج مع زر إعادة ضبط الفلاتر.

2. **صفحة المصنع (Factory Tour View):**
   * معرض المنتجات المصنعة محليًا («ماذا نصنع؟»).
   * مسار تفاعلي لمحطات الجولة بالأرقام (المحطة 1 إلى 4)، الضغط على أي محطة يظهر صورتها ووصفها التفصيلي دون الاعتماد على المؤشر.
   * معلومات المدة، السعة، اشتراطات السلامة، ومواعيد الإتاحة.
   * شريط حجز ثابت للجوال وسطح المكتب.

3. **نموذج طلب الزيارة الخاصة (3 خطوات):**
   * **الخطوة 1:** تحديد الغرض (أكتشف / أتعلّم / أتعاون) مع إظهار الحقول المخصصة تلقائيًا (عدد الحضور للأفراد، بيانات الجهة والطلاب للمدارس، أو موضوع الشراكة للأعمال).
   * **الخطوة 2:** اختيار الموعد والسؤال الاختياري «وش أكثر شيء متحمّس تشوفه؟».
   * **الخطوة 3:** مراجعة ملخص الطلب، وتأكيد بيانات المنسق.
   * إصدار رقم طلب فوري (`REQ-2026-XXXX`) بحالة «بانتظار موافقة المصنع» وتأكيد أنه ليس حجزًا نهائيًا حتى موافقة المصنع.

4. **الفعاليات المجدولة المعلنة:**
   * مسار حجز مباشر بمقاعد محددة وتحديث فوري للمقاعد المتبقية مع منع تجاوز السعة أو التسجيل المكرر.

5. **صفحة زياراتي (My Visits):**
   * تصنيف الزيارات القادمة والسابقة مع سجل تدقيق الحالات (Audit Log).
   * إدارة الموعد البديل: زر لقبول الموعد البديل أو الاعتذار عنه.
   * عند التأكيد: إصدار **بطاقة تصريح الزيارة (Ticket Pass)** متضمنة البوابة، وقت الحضور، والتعليمات.

6. **جواز الاكتشاف (Discovery Passport):**
   * 5 خانات للأختام للقطاعات الخمسة.
   * **قاعدة المنح الصارمة:** يُمنح الختم فقط بعد تسجيل المصنع لحضور الزائر الفعلي واكتمال الجولة (`completed`).

7. **لوحة إدارة المصنع (Factory Dashboard):**
   * معزولة لكل مصنع (يصل المدير فقط لطلبات مصنعه).
   * إحصائيات: طلبات جديدة، زيارات قادمة، وإجمالي الزوار.
   * زر إيقاف / تفعيل استقبال الطلبات مؤقتًا.
   * قبول الطلبات، أو اقتراح موعد بديل مع السبب، أو الاعتذار.
   * زر «تسجيل الحضور واكتمال الزيارة» الذي يمنح ختم الجواز للزائر فورًا.
   * إنشاء فعاليات عامة معلنة جديدة.

8. **إدارة المنصة (Platform Admin):**
   * مراجعة طلبات الانضمام الواردة من نموذج «سجّل مصنعك».
   * اعتماد ونشر المصنع في المنصة أو الرفض مع ذكر السبب (لا يُنشر أي مصنع جديد تلقائيًا).
   * مؤشرات المنصة الشاملة وزر إعادة تهيئة البيانات التجريبية.

9. **مبدّل الصلاحيات (Persona Switcher):**
   * من شريط الرأس أو شريط الجوال: التبديل بين الزائر، مديري المصانع الخمسة، ومدير المنصة بضغطة واحدة لتسهيل تجربة جميع الأدوار وسيناريوهات العمل.
